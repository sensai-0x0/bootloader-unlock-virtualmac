# Vulnerability Researcher

Paired with the bootloaded modification tool, vulnerabilities and exploits can be evaluated at the speed of thought.

A set of agents and sub-agents where required evaluate the target. At this stage there is no intent to point this tool at real hardware.
The virtualised MacOS environments that the bootloader modification tool uses serve the purpose required.
In fact the Vulnerability researcher already identified a simple low level vulnerability in our virtualized M6 Pro virtual OS.
